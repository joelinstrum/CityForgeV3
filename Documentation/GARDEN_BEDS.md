# Georgian mixed garden beds

Garden now offers two complete 18th-century-inspired mixed beds: `georgian-mixed-garden-square-v01` (4 × 4 m) and `georgian-mixed-garden-rectangle-v01` (6 × 3 m). Both contain repeated flower masses, separate shrubs, visible soil and a contained stone edge across the whole footprint. The prior `georgian-flower-thicket-border-v01` (4 × 1.5 m) stays loadable for existing saves but is removed from the Garden catalog; it was too narrow for the requested full-bed composition.

The planting plan is an orthographic photographic texture on the ground. Upright crossed flower and shrub cutouts, plus a low 0.06 m physical rim, give height at the Lot Editor's angled camera. The rim and a matching 0.18 m overlay now use muted charcoal-brown; the overlay covers the white trim baked into the plan image without altering its source art. The current `Untitled Lot` uses 30° elevation and 45° azimuth; some native 3D lots use 20° elevation. The objects are real rotatable assemblies, not fixed-angle isometric sprites. The existing `PlacedProp` ID, center anchor, quarter-turn, selection, Undo and manual Save routes remain in charge. The rectangle swaps to 3 × 6 m at odd turns; the square remains 4 × 4 m. Neither type changes the save schema. Worker/labor code is untouched.

Summer uses the full floral image and upright clumps. Spring uses fresher, partly transparent flowers; autumn mutes and thins bloom color; winter switches to separate dormant plan images and woody shrub cutouts and hides flower cards. These are visual presets, not simulated growth. Art originals, the isometric study and lineage are under `ArtStudies/GeorgianGardenBedsV01/`.

Validation: `Validation/georgian-garden-beds-v01/` and the later `Validation/georgian-clipped-hedges-v01/` live comparison. The initial five isolated renders used 20° elevation. Follow-up captures use the actual open Lot Editor Game camera at 30° elevation and 45° azimuth, including current Detail zoom and a temporary closer view. Those temporary presentations were removed and the active lot JSON was unchanged. Dense repeated-placement performance, physical-mouse interaction and a saved-lot regression run remain unverified. The last forest and regional 39/39 and 83/83 suites do not test these beds.
