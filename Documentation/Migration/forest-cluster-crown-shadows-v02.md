# Forest cluster crown shadows v02

Joe's SimCity 4 comparison is a visual reference only; no asset was copied or ported. The prior leafed-cluster projection was one soft ellipse per billboard. It read as a generic dark patch, and its sideways axis could become parallel to the sun direction, collapsing the ground triangles until the shadow effectively disappeared.

Leafed clusters now project three, four, or five overlapping crown silhouettes for compact, legacy, and large artwork, respectively. Their centers are deterministic offsets inside the single cluster's artwork bounds, with small matching ground-contact areas. The actual fan geometry always uses a ground-plane axis perpendicular to the sun ray, so it remains two-dimensional at every time of day. Each crown has a defined interior and a short outer feather. Winter retains its lighter shared footprint. Individual trees and other flora are unchanged.

This remains one terrain contact query and one shadow mesh per cluster, using the existing flora batch and material. There is no per-frame district scan, extra renderer, or draw pass. The leafed mesh grows from 66 vertices to 150 (compact), 200 (legacy), or 250 (large). In an isolated Unity 6.1 EditMode fixture, 33 targeted forest/flora tests passed, including a non-degenerate-triangle check for multiple sun directions. A 384-cluster season transition retained 32 flora batches and 97 bounded slices; max slice was 15.97 ms and p95 13.87 ms, with zero managed bytes reported by that test's per-slice allocation check. The previous 66-vertex short run reported max 13.95 ms and p95 12.60 ms. These are short CPU measurements, not a controlled GPU/draw-call or long-duration frame-time profile; the larger meshes should still be assessed in Joe's dense live district.

`Documentation/Previews/forest-cluster-crown-shadows-v02.png` is a synthetic close-up render of one compact and one large summer deciduous cluster in the isolated fixture. It is a visual QA preview, not production forest placement. Joe's live Unity editor was not driven.
