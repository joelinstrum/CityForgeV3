# Deciduous forest canopy visual experiment v01

Four new transparent PNGs in `Assets/CityForgeV3/Resources/CityForgeV3/Flora/ForestCanopyFarV01/` are original imagegen artwork, not edits to the established `ForestClustersFamilyMixV03/V04` sources. The user's aerial forest photograph was a reference for overlapping, rounded, varied-height canopy masses rather than legible individual leaves. The existing City Forge cluster was a camera/scale reference. Built-in imagegen generated separate large and compact summer compositions, then seasonal edits supplied restrained autumn derivatives. The large autumn image received a further lower-saturation revision. All four final assets are 1536 × 1024 RGBA cutouts with their original alpha channels preserved. No canonical source asset was overwritten.

This is deliberately an art-direction experiment. Deciduous compact and large clusters use the same canopy artwork at **all** district zoom levels in spring, summer, and autumn so close-up readability can be assessed without a costly zoom-boundary sprite replacement. Winter, mountain, tropical, individually harvestable firs, and Lot Editor trees keep their previous art. Existing cluster instance IDs, simulation, selection, placement, and save data are unchanged. Reverting the experiment requires only removing the new resource-path preference; the previous art remains present.

Isolated-Unity autumn screenshots from a synthetic 170-cluster district are saved as `Documentation/Previews/forest-canopy-v01-region-autumn.png` and `Documentation/Previews/forest-canopy-v01-close-autumn.png`. They are visual QA, not additional game textures or a replacement for Joe's play-mode check.

Seasonal replacements still happen through shared cached sprites and spatial batches. The prior season-boundary snapshot of every cluster has been removed: a registry enumerator now advances only the configured per-frame budget and restarts on local add/remove. In an isolated Unity 6.1 EditMode fixture with 384 deciduous clusters, the summer and autumn states each used 32 flora mesh batches. At four clusters per frame, the swap needed 97 slices; the observed maximum slice was 19.34 ms and p95 was 16.95 ms in the final headless-editor run. The allocation counter reported zero bytes per slice, but that result is not treated as a reliable allocation profile. This is a short diagnostic, not long-duration gameplay profiling; actual GPU draw calls and frame-time distribution in Joe's live editor remain to be checked. The smaller budget favors fewer spikes over an instantaneous season change.

Generation prompt intent: photographic 3D-rendered eastern North American hardwood crowns from a high oblique camera; organic overlap, muted greens, broad light/dark crown structure, nearly hidden trunks, no ground or sky, and transparent antialiased edges. Autumn edits preserve the composition while introducing mostly olive/yellow-green with scattered subdued ochre and rust. Built-in imagegen was used; no CLI/API generation.
