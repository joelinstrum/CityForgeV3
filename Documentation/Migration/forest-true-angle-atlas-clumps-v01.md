# True-angle deciduous forest clumps V01

Joe supplied three 1536×1024 transparent sheets in `/Users/joelinstrum/Downloads/flora` on 2026-09-24. Their 4×3 grids contain twelve individual true-angle trees. The original files remain untouched; byte-for-byte copies are in `Assets/CityForgeV3/Resources/CityForgeV3/Flora/ForestTrueAngleAtlasV01/` as `true-angle-trees-summer.png`, `true-angle-trees-fall.png`, and `true-angle-trees-winter.png`. Spring uses the summer sheet. The earlier V03 canopy assets remain available but are no longer used for district deciduous compact/large clumps.

`ForestTrueAngleCluster` slices the imported sheets as cached full-rect Unity sprites without creating separate raster derivatives. Three deterministic diamond-like arrangements each exist for compact (four trees) and large (seven trees) clumps. Each clump remains one district flora/selection handle. Its tree quads, including seasonal swaps, enter the existing spatial flora batch; individual trees do not add GameObjects, renderers, or draw calls. Shadows use corresponding tree positions. Terrain height is sampled at the clump's local tree anchors on placement or movement, not per frame. Other flora families are unchanged.

Validation in an isolated project copy: 34 focused EditMode tests passed, including atlas/season alignment, one-batch geometry, zoom invariance, and a 384-clump season transition. The dense fixture produced 16 flora batches in summer and autumn, 97 bounded update slices, 11.36 ms maximum slice and 9.70 ms p95, with zero reported per-slice managed allocation. The previous V03 fixture recorded 32 batches, 19.34 ms maximum and 16.95 ms p95 for the same count and budget. These are short headless-editor runs, not actual GPU draw-call or long-duration frame-time profiles; the zero-allocation counter is not a definitive allocation profile. A graphics-mode fixture rendered the summer compact and large clumps; final visual judgment at Joe's actual game zoom and all seasons still belongs in his open editor. No live-editor control or automatic player save was performed.
