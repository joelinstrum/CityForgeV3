# True-angle fir atlas V01

Joe supplied `fir-trees.png` and `fir-trees-winter.png` in `/Users/joelinstrum/Downloads/flora` on 2026-09-24. The originals remain untouched. Byte-for-byte copies live in `Assets/CityForgeV3/Resources/CityForgeV3/Flora/ForestTrueAngleFirAtlasV01/`. Each 1536×1024 sheet contains fifteen trees in a 5×3 arrangement. Spring, summer, and autumn use the snow-free sheet; winter uses the snowy sheet.

The existing `ForestTrueAngleCluster` now slices fir cells through cached Unity sprites. Seasonal crop boundaries follow the transparent gaps in each row; stable source-coordinate trunk anchors prevent winter swaps from shifting trees. Mountain compact and large clumps use three deterministic four- and seven-tree diamond layouts. Generated or planted individual `cilician-fir`, `medium-balsam-fir`, `medium-fraser-fir`, and `medium-blue-spruce` records use varied individual slots, as do their Lot Editor presentations. Saved flora identities, generated-tree records, and the special fallen/stump artwork for harvestable Cilician firs remain unchanged.

District firs enter the existing spatial flora mesh batch through one atlas sprite key per season, without a renderer for every tree. Clumps keep one selection handle, terrain-grounded pieces, and their shared projected shadow. No work is added per frame beyond the existing bounded seasonal swap. In an isolated 384-fir-clump test, both seasons used 16 flora batches; the winter transition took 97 slices with 9.91 ms maximum and 8.40 ms p95 slice time, and the managed allocation counter reported zero bytes per slice. These are short headless-editor measurements, not GPU draw-call or long-duration frame-time profiles. Summer and winter visual previews and 52 focused EditMode tests used an isolated Unity project copy; Joe's live editor and player saves were not touched.
