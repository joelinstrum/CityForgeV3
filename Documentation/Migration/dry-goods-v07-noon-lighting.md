# Noon lighting trial v07

Joel accepted the v06 improvement but requested a noon lighting pass: the game loses color/contrast and wood detail compared with Blender. This is a review candidate, not a claimed exact preview match.

For noon, district root-level scene directional lights are now temporarily suppressed, as already implemented for afternoon. Native building noon sun intensity is 1.05 (previously .55 plus an unmanaged 1.0 scene light), multiplied by the existing environment slider. Hosted noon now follows the canonical world-space shadow ray. With native buildings present, noon ambient changes from Flat (.32,.34,.37) to Trilight: sky (.42,.44,.47), equator (.30,.305,.315), ground (.12,.115,.105), multiplied by the existing ambient slider and .7 in rain. No textures, geometry, saturation multipliers or global color-space settings changed. Other time presets retain their previous settings; night restores the root scene light.

Inspection: controlled before/after captured at the same camera in normal docked Unity Game view, using a temporary district and a saved Dry Goods lot read without mutation. First low-fill/weak-sun trial was rejected as too dark; final balanced candidate retains roof/stone brightness with darker facade fill. Night inspected after switch. Eight focused tests pass: four door regressions, noon and afternoon ray alignment, noon and afternoon scene-light restoration. These tests do not establish artistic acceptance. See revision-tests.xml and lighting reports.

Remaining preview differences: noon sun orientation differs from the studio reference; game uses Gamma color space; hosted beauty meshes disable shadow casting and therefore lack much of the preview's fine self/contact shadowing. These were identified, not globally redesigned in this pass. Ambient-occlusion/contact shadows are a sensible next isolated trial if Joel wants more depth. Native building lighting also follows existing per-lot environment values; a saved custom sun/ambient slider can alter this result. Mixed-lot shared lighting ownership remains existing architecture.

Lineage: v06 native model unchanged -> v07 game lighting trial. Original v04 and v05/v06 assets remain intact. Before source snapshots and current scripts are recorded here. `DryGoodsNoonReview.cs` supplies editor-only baseline/candidate diagnostics; baseline recreates the former noon lighting at default environment values, and candidate reapplies the production preset.
