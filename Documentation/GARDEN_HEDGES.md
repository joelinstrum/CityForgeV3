# Georgian clipped hedge plots

The Garden library now offers `georgian-clipped-hedge-square-v01` (4 × 4 m) and `georgian-clipped-hedge-rectangle-v01` (6 × 3 m). Each is a complete, rotatable formal plot: a continuous clipped perimeter, smaller interior hedge islands, and exposed dark earth. The hedges use one combined beveled mesh with a shared photographic leaf material. They are ordinary `PlacedProp` records, so the existing ground anchor, quarter-turn rotation, selection, Undo and manual-only Save routes apply. The rectangle footprint swaps to 3 × 6 m on odd turns. No save schema or labor code changed.

The leaf source is `ArtStudies/GeorgianClippedHedgesV01/clipped-leaves.png`; the byte-identical runtime copy is in `Resources/CityForgeV3/Garden/GeorgianClippedHedgesV01/`. Enlarged leaf UVs preserve texture at Lot scale. Spring is slightly fresher, summer full green, autumn muted, and winter darker subdued evergreen. This is visual seasonality, with no growth or labor simulation. Existing mixed flower beds now render a low charcoal-brown edge over the pale trim baked into their plan art.

Validation evidence is in `Validation/georgian-clipped-hedges-v01/`. Temporary, unsaved presentations were captured with the active Lot Camera at Detail zoom, 30° elevation and 45° azimuth, including a 90° rectangle turn and winter hedge tint. An isolated `LotEditorSession` JSON round trip preserved both new IDs and the quarter turn, and the rotated footprint check returned 3 × 6 m. The active lot JSON was identical before and after, and no Save was invoked. Physical UI placement, selection, Undo and saved-file regression remain to check during normal play. The earlier forest 39/39 and regional 83/83 runs do not validate this work.
