# Georgian mixed beds V01 validation

Unity refreshed and compiled after the new Garden assemblies and catalog changes. A first in-editor fixture attempt stopped when the editor reported an active `Untitled Lot`; no user save was written. Validation then created temporary geometry far from the lot, rendered with a dedicated orthographic camera calibrated to the Lot Editor's 45° azimuth and 20° elevation, and destroyed the stage. The active lot JSON was identical before and after. Square summer, rectangle summer, rectangle at 90°, and both winter states were rendered and visually inspected. The rectangle's quarter-turn footprint was checked as 3 × 6 m. `qa.txt` records the isolated run.

The renders prove that the artwork and raised shrubs translate into the camera angle, but they do not prove full Lot Editor mouse placement, selection, UI catalog submit, Undo, or a user save round-trip for these new IDs. Those behaviors use the existing placed-prop path. No dense repeated-placement profiling was run. Prior forest 39/39 and regional 83/83 results are unrelated to this garden work.

Follow-up on the live `Untitled Lot` found that its actual Game camera uses 30° elevation and 45° azimuth at Detail zoom. Two temporary `CreatePropPresentation` instances were placed on the current lot ground solely for capture. `summer-in-game.png` shows both; `rectangle-90-in-game.png` shows the rotated rectangle; `garden-close-in-game.png` is a synchronous render through that same camera with a temporary closer orthographic size. The camera size was restored, both presentations destroyed, and the active lot JSON compared byte-for-byte equal. `game-camera.txt` records the live camera and result. These are in-game appearance checks without adding placed-prop records or calling Save; mouse placement, selection, and Undo still need separate QA.
