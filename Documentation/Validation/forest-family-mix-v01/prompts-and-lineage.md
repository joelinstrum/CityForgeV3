# Forest family mix V01 prompts and selected outputs

Tool: OpenAI built-in image generation.

Shared generation direction: use the approved realistic cluster as a visual
style reference; make a high-detail photographic, single flattened forest
billboard on a square transparent RGBA canvas; use a narrow shared root line;
include no ground plane, baked shadow, text, or watermark.

Compact prompts specified five trees: deciduous `4 deciduous + 1 fir`, mountain
`4 fir/spruce + 1 deciduous`, and tropical `2 fan palms + 1 date palm + 2
tropical broadleaf`. Large prompts specified nine trees: deciduous `8 + 1 fir`,
mountain `8 + 1 deciduous`, and tropical `3 fan palms + 2 date palms + 4
tropical broadleaf`. Seasonal edit prompts preserved exact silhouettes and tree
positions; autumn recolored deciduous leaves only, while winter removed those
leaves only and kept firs green with no snow.
