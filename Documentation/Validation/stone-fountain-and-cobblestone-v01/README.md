# Supplied fountain and cobblestone validation

`fountain-on-supplied-cobblestone.png` shows the supplied FBX through its Lot
presentation and the supplied cobblestone through the Lot ground shader on a
temporary isolated layer. `review.txt` records resource, footprint, ground
anchor, and in-memory serialization checks. No user lot was saved. The focused
EditMode tests are pending while Unity remains in Play mode.
