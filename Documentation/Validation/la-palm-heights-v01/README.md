# LA palm height variants

Two new planting IDs, `la-fan-palm-a-medium` and `la-fan-palm-b-medium`, share the exact V01 textures and trunk-foot pivots of their respective tall versions. Each uses a pixels-per-unit value 4/3 of its tall counterpart: A 70 → 93.33334 and B 80 → 106.6667. Resulting visible height is 75% while trunk, crown and proportions remain unchanged. The original planting IDs retain their prior scale.

Fresh Unity `palm-heights-review` verified shared paths, exact height ratio, evergreen season routing, Tropical family and California/Mediterranean planting eligibility. `palm-heights-game` captured the tall/medium pairs side by side in the current Lot camera with temporary renderers, then removed them. Lot JSON was unchanged. The preview uses current Lot lighting and does not include placed-tree shadows.
