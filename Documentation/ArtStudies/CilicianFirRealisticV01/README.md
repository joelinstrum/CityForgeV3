# Realistic Cilician fir — V01

This is the approved source study for the standing, harvestable Cilician fir.
It replaces only the billboard shown while the tree is standing. The existing
falling animation sheets and stump remain the harvest presentation.

`cilician-fir-evergreen.png` was generated with the built-in image generation
workflow as an isolated RGBA cutout: a mature blue-green Cilician fir with a
visible trunk, irregular layered boughs, and no ground shadow or scenery. The
runtime copies are under
`Assets/CityForgeV3/Resources/CityForgeV3/Flora/CilicianFirRealisticV01/`.
They are deliberately identical spring, summer, autumn, and winter copies:
Cilician fir stays evergreen.

The original TreeRepairsV01 fir art remains in the repository. This study is a
new versioned asset and does not change saved flora IDs, yields, worker logic,
Undo, or manual saving.
