# Photographic Willow summer studies

Two summer studies made with built-in imagegen on 2026-09-17; neither is installed in-game. V01 uses the existing vendor-willow summer image for species silhouette and approved Silver Maple V02 for photographic/camera style. V02 revises V01 leaf-curtain texture. Both preserve RGBA source files in the versioned workspace directory.

## V01 prompt

Create a NEW photographic summer WEEPING WILLOW (Salix babylonica) tree cutout for City Forge. Input Image 1 is the existing in-game willow: reference for species and unmistakable cascading silhouette ONLY. Input Image 2 is the approved Silver Maple: reference for restrained photographic fidelity and elevated orthographic camera ONLY. The willow should have a sturdy irregular trunk visible beneath a broad fountain-like crown. Long, naturally varied pliant branchlets and fine narrow lance-shaped leaves hang downward in overlapping curtains, with believable translucent gaps and uneven lengths. Foliage natural medium and soft olive green, subtle sunlit variation; no cartoon blobs, uniform hair-like tassels, topiary symmetry or white leaf sparkles. Gray-brown bark with natural subdued texture; root flare at clear centered ground contact. Photographic botanical cutout as if shot in soft neutral daylight from an elevated platform with long lens, camera looking down about30 degrees, tree upright. Entire tree in 1024x1536 portrait frame with canopy and roots clear of edges. True transparent RGBA including holes between branches; no blurry colored backdrop, vignette, glow, haze, ground, cast shadow, props, labels, people, water or text. Summer only.

## V02 prompt

Edit this willow tree image to improve photographic naturalism. Preserve its exact broad weeping-willow silhouette, trunk, root-foot placement, main sweeping limbs, elevated orthographic camera and entire 1024x1536 frame. Targeted change: replace conspicuously regular, identical hanging leaf tassels with many irregular fine pliant willow branchlets at mixed lengths, angles and density, each bearing very small individually varied narrow lanceolate leaves. Some strands sparse and almost bare, some denser; natural uneven gaps, dark interior, varied overlap and softly lit olive/medium greens. End branches taper organically, without repeated braided or feather patterns. Subtle photographic texture and natural daylight, restrained contrast, no plastic CGI crispness or cartoon. Preserve true transparent RGBA cutout; no colored background, halo, haze, ground, cast shadow, props or text. One summer willow.
