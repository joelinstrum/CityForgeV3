# Macro Grass V02 source

`colonial-countryside-grass-v02.png` is a simplified 4096 × 4096 RGB terrain albedo for approximately 75 m × 75 m of ground. It replaces V01's conspicuous mid-frequency tan/green mottling and mirrored quadrants with quieter muted-green variation, restrained grain, and sparse faint dry discoloration. V01 remains in the project as a recoverable comparison asset.

The built-in image-generation tool edited V01 in two passes. The selected 1254 × 1254 result was resized to 4096 × 4096, lightly softened, and given a localized 512-pixel smooth edge blend. In-game review showed that Unity amplified even restrained green-to-tan color shifts and recognizable mid-scale luminance silhouettes. The final diagnostic-friendly asset therefore applies a 180-pixel broadening pass and carries the generated composition only as a two-level luminance drift over a consistent muted olive-green base; it contains no baked green-to-tan hue swing. Opposite one-pixel borders are byte-identical without constructing the full image from mirrored quadrants.
