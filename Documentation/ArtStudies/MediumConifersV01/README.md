# Medium conifers V01

Six 1024×1536 RGBA cutouts generated with the built-in imagegen tool. Runtime copies live in `Assets/CityForgeV3/Resources/CityForgeV3/Flora/MediumConifersV01/`. No older fir artwork was overwritten.

- `balsam-fir-snowfree-study-v01.png`: Abies balsamea, medium naturally loose cone with deep dark green soft short flat needles and layered branches. The existing realistic Cilician fir was used only as a detail/lighting reference.
- `fraser-fir-snowfree-study-v01.png`: Abies fraseri, more compact, broad-shouldered cone with dark emerald needles and subtle silver undersides.
- `blue-spruce-snowfree-study-v01.png`: Picea pungens, stiff tiered branches and powdery steel-blue needles, distinct from snow.

Each `*-snowy-study-v01.png` is an imagegen edit of its snow-free parent, preserving tree structure, with patchy snow on selected upward-facing branch surfaces and green/blue needles still visible. All prompts specified full isolated tree, near-orthographic upright camera, transparent background, no ground, baked shadow, decoration, or text. The snow variants do not add snow to the trunk base.

Runtime seasonal mapping uses the snow-free texture for Spring, Summer and Autumn, and the snowy texture for Winter. These are three manual planting species, separate from older fir IDs and procedural forest clusters.
