# Photographic palms V01

Four 1024×1536 RGBA cutouts generated with the built-in imagegen tool. These source studies are preserved here. Identical runtime copies live in `Assets/CityForgeV3/Resources/CityForgeV3/Flora/PhotographicPalmsV01/`; the existing `date-palm` and its legacy artwork remain unchanged.

- `date-palm-tall-study-v01.png`: Phoenix dactylifera, 12–14m implied tall date palm, substantial fibrous diamond-pattern trunk, broad feather-frond crown and modest dates. Prompt specified a grounded, upright near-orthographic tree without scenery or baked shadow.
- `date-palm-short-study-v01.png`: separate shorter Phoenix dactylifera individual, 7–9m implied, extra thick stout trunk, lower lush feather-frond crown, discreet dates. Prompt specified distinct silhouette and trunk proportion.
- `la-fan-palm-a-study-v01.png`: Washingtonia robusta, very tall 22–25m implied, slender straight ringed trunk, high relatively sparse radial fan-leaf crown with some retained old leaves beneath.
- `la-fan-palm-b-study-v01.png`: second Washingtonia robusta, about 18–21m implied, slender subtly irregular ringed trunk and fuller, tidier green fan crown with short pruned collar.

All prompts asked for photorealistic foliage/bark, true transparency through leaf gaps, upright near-orthographic camera, no ground, shadow, backdrop, props or text. Palms are evergreen in the runtime and use one cutout per species for all four seasons.
