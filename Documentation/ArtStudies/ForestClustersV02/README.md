# Mixed forest clusters V02

Five summer visual prototypes generated with built-in image_gen on 2026-09-16. Each image depicts five trees, including one or two firs. Exact prompts and generated source lineage are in prompts.json. The approved ForestClustersV01 fir cluster and existing LegacyTreesV01 oak-summer, vendor-oregon-ash-summer and maple-summer artwork were supplied as references. Original sources remain unchanged.

| Image | Intended species mix |
| --- | --- |
| [01](mixed-cluster-01.png) | Two firs, oak, ash, maple |
| [02](mixed-cluster-02.png) | Fir, two oaks, ash, maple |
| [03](mixed-cluster-03.png) | Two firs, two maples, ash |
| [04](mixed-cluster-04.png) | Fir, two ashes, oak, maple |
| [05](mixed-cluster-05.png) | Two firs, two maples, oak |

All use transparent backgrounds and baked preview ground shadows. Prompt targets shallow 20-degree orthographic elevation and 45-degree azimuth; exact camera matching and scale remain unverified in Unity. Species identities are intended art direction, not botanical validation. Some side foliage is close to the frame edge and needs padding/framing cleanup before production. Tree and shadow layers must be separated for the game's dynamic sun.

These images are art studies, not registered flora items. No forest generator, save, harvesting, worker, or seasonal code changed. Seasonal derivatives and runtime performance validation remain future work.
