# Realistic London plane — V01

This is the seasonal master study for the realistic London Plane family.

* Summer has a broad, irregular mature canopy and characteristic pale mottled
  plane bark.
* Spring uses an open crown with small new leaves and visible buds.
* Autumn combines muted gold, amber, ochre, olive, and residual green leaves.
* Winter is completely leafless, retaining the open branch network and pale
  trunk without snow.

All images are RGBA cutouts with no ground or baked shadow. Plane A is the
first realistic runtime replacement. Plane B is a separate high-isometric
summer/spring/autumn comparison variant; its legacy winter cutout remains until
the matching bare-branch study is approved. Plane C remains legacy art. Existing
flora IDs and saved placements are unchanged.
