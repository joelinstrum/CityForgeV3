# City Forge flat-color road templates v1

Each 1024 × 1024 file represents one 10 × 10 meter tile. SVG files are editable masters; PNG files are transparent previews/import candidates.

## Semantic colors

- `transparent`: `#00000000`
- `road_surface`: `#59636B`
- `sidewalk_surface`: `#D4A66F`
- `curb`: `#E8DFCF`
- `shoulder`: `#9A8467`
- `pedestrian_surface`: `#C98972`
- `center_marking`: `#E7C95B`
- `direction_guide`: `#68C7D4`

Replace a semantic color with a seamless material while retaining the exact silhouette and registration. Keep traffic rules in `template-library.json`; do not infer them from painted pixels.
